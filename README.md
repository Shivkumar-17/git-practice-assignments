# Git Practice Assignments

College Event Portal and Git workflow examples for Shivakumar S.

## Project

Open `index.html` in a web browser. The static project has `index.html`, `events.html`, `contact.html`, and `style.css`. No installation or build is required.

## Branches

- `main`: base portal and supporting files.
- `feature-attendance`: an attendance page developed separately from main.
- `feature-homepage`: homepage changes proposed in [pull request #1](https://github.com/Shivkumar-17/git-practice-assignments/pull/1).
- `feature-dashboard`: dashboard feature; main has three newer commits for the rebase exercise.

## Practice topics

1. Initialize a local repository, stage, commit, connect a remote, and push.
2. Create and publish a feature branch.
3. Inspect working-tree and staged differences before committing.
4. Open a pull request, obtain a real teammate review, merge, delete the feature branch, and synchronize main.
5. Restore an unwanted unstaged edit and resolve a merge conflict.
6. Fetch origin/main, rebase the dashboard feature, resolve conflicts if any, and push with --force-with-lease when rewriting an already published branch.

## Evidence and scope

Project files and feature branches were published through the GitHub integration. Pull request #1 is open for a real review; no independent approval, merge, or feature-branch deletion is claimed. Restore, merge-conflict resolution, and rebase commands are provided as assignment answers; those local exercises are not represented as completed on this remote repository.
